# Catstella 路线图

## 当前版本

- 双端桌宠显示优先级、角色与壁纸联动已接入；网页壁纸支持淡入过渡。
- 在线更新检测：桌面和网页扩展分别读取 GitHub Releases，提示可用的正式版本。安装仍由用户决定。
- 在线桌宠、壁纸和配色从仓库的 `online-assets/` 读取。检测到可安装的内容时提示，下载后可从本地图库选择。
- 自动碎碎念：双端可分别开启，默认关闭。空闲时播放本地短句，不读取聊天、不调用模型。

## 下个版本（暂定）

### 修复

- **Web 额度倒计时归零后没有刷新。** 目前倒计时结束后仍显示上一周期的用量和告警，倒计时的位置会变成重置时刻。到点后重新获取对应周期的官方用量；新数据尚未到达时显示等待更新，不把旧值当成当前状态，也不提前显示 0%。分别验证 5 小时和每周额度，覆盖切回后台标签页的情况。
- **Web「用量限额」页面卡片后方有半透明遮罩。** 去掉卡片区域背后的大块遮罩，保留各卡片自身的底色、边界和文字对比度。用量页以外的壁纸和毛玻璃样式保持原样。
- **替换 Web 原发光区域的黑雾。** 在首页截图场景中分别关闭桌宠光晕、立绘投影和壁纸压暗层，定位实际来源。确认后优先换成贴边的主题色柔光或细描边，保留思考、低额度等状态的辨识度；如果柔光在深浅壁纸上都难以看清，直接去掉这层装饰。和用量卡片背后的遮罩分开验证。
- **AGY 从后台回到前台时壁纸瞬切。** 如果宿主窗口在后台期间切换过壁纸，重新激活时应从上次显示的壁纸淡入最新一张。后台连续轮播时不补播中间的壁纸；同时检查网页同步壁纸时是否出现相同问题。
- **Web 摸头没有反馈动画（v0.6.0 已知问题）。** 短按桌宠头部时恢复可见的动作反馈；表情是否触发仍按互动规则决定。长按、拖动和滑动不算摸头。

### 功能与实测

- **优化双端桌宠互动。** 主动刷新额度成功后播放一次「得意」表情；检查连续摸头的节奏、动作衔接，以及表情预览或其他状态是否会提前打断反馈。
- **实时状态「喵言喵语」。** 参考 [dsh-pet 的状态气泡](https://github.com/zhu1090093659/dsh-pet/blob/main/README.md)，用短台词反馈 AGY 和 Web 的实际状态。额度侧沿用已有的耗尽提醒，在确认官方额度重置后补一条恢复提示；任务侧先覆盖能确认的阶段，例如 Web 正在生成或已完成，AGY 正在思考、执行工具、等待确认或已完成。AGY 能可靠拿到任务步骤时，再提示当前进行到哪一步；拿不到细节时只显示已确认的阶段。状态台词与空闲碎碎念分开，按事件去重，不引用聊天正文或工具参数。
- **优化双端设置界面。** 参考 [Gemini Quota Widget](https://github.com/smiththomson580-star/gemini-quota-widget) 把额度气泡和个性化设置分开的思路。Catstella 自己实现：整理常用设置、桌宠和壁纸的入口，让预览、当前选中项以及「同步桌面／独立设置」更容易辨认，并兼顾桌面设置窗口和浏览器窄面板。
- **实测在线壁纸与桌宠。** 用正式 GitHub 图库验证新内容提示、预览、手动安装、切换、重启后保留和双端同步；分别检查 Edge、Firefox 和桌面端已有的入口。验证 GitHub 直连失败时提示清楚，已安装素材仍可使用。

## 中长期探索

- **Gemini Web 2025 怀旧主题（可行才做）。** 首选 2025 年 5 月的 2.5 时期：有[完整首页截图](https://aisig.ancstor.org/handouts/2025-05-26-aisig-gemini.pdf)和[网页模型菜单截图](https://9to5google.com/2025/05/13/gemini-model-picker/)，特征是左上角模型菜单、侧栏聊天历史、问候语和有轮廓的输入框。对照 11 月 3 Pro 首发时的[实际对话与思考区截图](https://gigazine.net/news/20251119-google-gemini-3/)；模型菜单在 10 月下旬就已[移入输入框](https://9to5google.com/2025/10/23/gemini-model-switcher-redesign/)，12 月的[新版首页](https://9to5google.com/2025/12/03/gemini-web-redesign-dec-2025/)另有更黑的背景和「My Stuff」，不要混为同一版。先做可选外观，沿用现有网页交互；若 2.5 的普通对话布局缺少可靠参考，就只做有依据的部分，或搁置。

## 长期规划

- **Windows 浮动任务栏下的双端重影（实测仍复现）。** 前台窗口分类与任务栏焦点交接已做过缓解，但没有解决问题。后续需要用两端窗口可见性、焦点和切换时序的同一份记录定位，再在 Edge、Firefox 与多显示器场景回归。当前不再追加猜测性补丁。
- **双端记忆与人格同步。** 后续在独立的 Memosyne 项目里研究 DSH 社区的记忆实现与 Memmy，再设计两端的接入边界。这一版的碎碎念与该规划无关。
