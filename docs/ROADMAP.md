## 下个版本（暂定）

### 修复

- **恢复桌宠拖动与位置调整。** 之前的摸头重构误将拖动手势也算成摸头或吞掉了 pointermove 的坐标同步，导致桌宠完全无法按住拖拽调整位置。需恢复拖拽时的窗口坐标平移和磁吸停靠逻辑，并与摸头判定彻底解耦。
- **Web 额度倒计时归零后没有刷新。** 目前倒计时结束后仍显示上一周期的用量和告警，倒计时的位置会变成重置时刻。到点后重新获取对应周期的官方用量；新数据尚未到达时显示等待更新，不把旧值当成当前状态，也不提前显示 0%。分别验证 5 小时和每周额度，覆盖切回后台标签页的情况。
- **Web「用量限额」页面卡片后方有半透明遮罩。** 去掉卡片区域背后的大块遮罩，保留各卡片自身的底色、边界和文字对比度。用量页以外的壁纸和毛玻璃样式保持原样。
- **替换 Web 原发光区域的黑雾。** 在首页截图场景中分别关闭桌宠光晕、立绘投影和壁纸压暗层，定位实际来源。确认后优先换成贴边的主题色柔光或细描边，保留思考、低额度等状态的辨识度；如果柔光在深浅壁纸上都难以看清，直接去掉这层装饰。和用量卡片背后的遮罩分开验证。
- **AGY 从后台回到前台时壁纸瞬切。** 如果宿主窗口在后台期间切换过壁纸，重新激活时应从上次显示的壁纸淡入最新一张。后台连续轮播时不补播中间的壁纸；同时检查网页同步壁纸时是否出现相同问题。
- **Web 摸头没有反馈动画（v0.6.0 已知问题）。** 短按桌宠头部时恢复可见的动作反馈；表情是否触发仍按互动规则决定。长按、拖动和滑动不算摸头。

### 功能与实测

- **优化双端桌宠互动。**
  - **后台摸头计数与阶梯动态台词**：后台持久化记录每日摸头数与总摸头里程碑；在「喵言喵语」中根据摸头频次（0次冷落、几十次包浆、上千次爱意过载）动态解锁不同阶梯的傲娇/娇羞专属台词（台词无缝接入 applyHonorific 自定义称谓系统，适配用户在设置面板指定的称呼或默认模式）；
  - **刷新成功动效增强**：主动刷新额度拿到确认数据后，除「得意」表情外，增加专属轻盈小跳跃（Bounce）或耳灯星轨脉冲流光反馈，提升操作获得感；
  - **摸头判定与拖拽位移解耦**：拖动全权交由桌宠位置调整系统接管，摸头交互专注头部轻触交互，去掉冗余的防滑动/位移抑制逻辑，使摸头动作触发更干脆自然；
  - 检查连续摸头的节奏、动作衔接，以及表情预览或其他状态是否会提前打断反馈。
- **实时状态「喵言喵语」。** 参考 [dsh-pet 的状态气泡](https://github.com/zhu1090093659/dsh-pet/blob/main/README.md)，用短台词反馈 AGY 和 Web 的实际状态。额度侧沿用已有的耗尽提醒，在确认官方额度重置后补一条恢复提示；任务侧先覆盖能确认的阶段，例如 Web 正在生成或已完成，AGY 正在思考、执行工具、等待确认或已完成。AGY 能可靠拿到任务步骤时，再提示当前进行到哪一步；拿不到细节时只显示已确认的阶段。状态台词与空闲碎碎念分开，按事件去重，不引用聊天正文或工具参数。
- **优化双端设置界面。** 参考 [Gemini Quota Widget](https://github.com/smiththomson580-star/gemini-quota-widget) 把额度气泡和个性化设置分开的思路。Catstella 自己实现：整理常用设置、桌宠和壁纸的入口，让预览、当前选中项以及「同步桌面／独立设置」更容易辨认，并兼顾桌面设置窗口和浏览器窄面板。
- **Web 额度浮窗。** 参考 Antigravity 内建用量查看器，只保留仪表部分，提供适配主题的独立浮窗和桌宠气泡紧凑版。Web 设置增加独立的「同步反重力用量」开关，关闭时只显示网页额度，不影响其它联动。开启时 AGY 与网页用量分组显示，Argon 独立周额度放在 AGY 的 Gemini 分组第三行。
- **Web 界面样式（本地实现）。** 提供星空毛玻璃、简洁实色、Gemini 原生三种样式，与在线配色分开；原生模式保留桌宠入口。
- **实测在线壁纸与桌宠。** 用正式 GitHub 图库验证新内容提示、预览、手动安装、切换、重启后保留和双端同步；分别检查 Edge、Firefox 和桌面端已有的入口。验证 GitHub 直连失败时提示清楚，已安装素材仍可使用。
- **重制桌宠气泡右上角操作按钮。** 目前右上角两个按钮（同步/聊天与设置）的图标样式容易产生误导、交互不直观。计划结合后续整体 UI/UX 调整统一重制设计，明确各按钮功能认知，优化点击热区与气泡排版。

## 后续界面适配（未定版本）

- **统一「在线内容商店」（Catstella Hub / Store）。** 在设置中心用独立选项页聚合桌宠形象、壁纸与主题配色，替换分散的在线列表。支持应用效果预览、安装、更新、卸载与「收藏夹」快捷切换，明确标注已安装状态。

- **两个追加形象（中期）。** 适配两款全新 Gemini 拟人桌宠形象：一款先征求 B 站原作者授权，确认允许改编和随项目分发后再正式收录；另一款参考社区已有二创形象，自行设计并制作立绘。形象确定后适配双端尺寸、表情动作帧（得意、委屈、害羞、打瞌睡等）与动作预览，并接入在线内容商店供用户按需下载选用。

## 长期规划

- **Windows 浮动任务栏下的双端重影（实测仍复现）。** 前台窗口分类与任务栏焦点交接已做过缓解，但没有解决问题。后续需要用两端窗口可见性、焦点和切换时序的同一份记录定位，再在 Edge、Firefox 与多显示器场景回归。当前不再追加猜测性补丁。
- **双端记忆与人格同步。** 后续在独立的 Memosyne 项目里研究 DSH 社区的记忆实现与 Memmy，再设计两端的接入边界。这一版的碎碎念与该规划无关。
- **闲置时的双形态变身。** 桌宠空闲一段时间后有概率在两种形态之间切换，并播放配套过渡动画；互动时避免打断正在播放的动作。

## 设想（不承诺实现）

- **角色动画。** 探索类似 [dsh-pet](https://github.com/zhu1090093659/dsh-pet) 的角色动画，先评估立绘、动作素材和播放方式的成本。
- **架空世界观主题。** 想象 Gemini 是 Google MD1 时代或 2008 年的产品，设计对应的网页外观。这是虚构设计，与复刻真实的 2025 年界面分开；工程量较大，暂只保留概念。
- **Gemini Windows 客户端适配。** 社区的 [Gemini Quota Widget](https://github.com/smiththomson580-star/gemini-quota-widget) 已有类似适配。仅在 Catstella 有明确的额外需求时再评估，暂不排期。
