## 现有功能

- 网页设置和扩展菜单可在「星空毛玻璃」「简洁实色」「Gemini 原生」之间切换。实色保留壁纸和配色；原生保留桌宠，暂时隐藏网页皮肤与壁纸。旧版关闭皮肤的用户继续使用原生样式。
- 「同步反重力用量」默认开启，可独立关闭。关闭后气泡只显示网页额度，角色和壁纸照常联动。
- **Web 壁纸偶发瞬切。** 已修复重复通知提前提交同一张待切壁纸，以及后台通知晚于淡入完成时误提交画面的两条路径。用户现场的触发条件未确认，待登录页面实测。明确选择无过渡或系统减少动态时仍不播放淡入。

- 网页扩展独立检查 GitHub 的正式 Web 版本，显示更新提示，由用户选择何时安装。
- 主题和壁纸使用 Catstella 主仓库的 `online-assets/` 在线目录；下载的壁纸加入本地图库。
- 自动碎碎念默认关闭，开启后只在当前 Gemini 页可见、空闲时从本地选一句，不读聊天内容或调用模型。
