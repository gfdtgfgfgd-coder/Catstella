# Catstella Web 路线图

总路线图在桌面工作树的 `docs/ROADMAP.md`。本页记录 Web 扩展的实现和验收状态。已实现表示代码已接入，实机结果单独列出。

## 已实现

- [x] **在线内容商店。** 从常用设置在 Gemini 页内打开浮窗。按壁纸、桌宠样式、主题配色分栏，可按最近更新浏览。推荐与详情支持轮播，配色可预览欢迎页和阅读区。应用素材后保留焦点和浏览位置。
- [x] **界面外观。** 星空毛玻璃、简洁实色、Gemini 原生三种样式。壁纸不透明度与模糊程度拖动时预览，松手保存，图库保持稳定。
- [x] **用量展示。** 经典进度条和反重力式圆环。圆环面板随内容增高，无内部滚动，默认隐藏反重力模型用量，保留显式开启的设置。网页显示已使用百分比与账本重置时间，反重力显示剩余额度，Argon 保留独立周额度。独立浮窗仍为 Demo。
- [x] **设置浮窗。** 分类切换保持窗体大小，内容区独立滚动。开关与切换使用轻过渡，尊重系统减少动态设置。
- [x] **额度刷新。** 两个周期独立到点刷新，回到标签页补查，未确认周期时显示等待更新。确认手动刷新成功才播放动作。
- [x] **页面交互。** 用量限额页清除大块外层遮罩。思考区保留 Gemini 原生操作，复制提示优先靠近复制按钮。
- [x] **桌宠互动。** 拖动、方向调整与短按分开。短按有反馈，拖动、长按和唤醒不计入摸头。计数存本机，并接入基米的摸头台词。空闲碎碎念可独立开启。
- [x] **状态台词与称呼。** 可跟随桌面或设定网页端称呼。今日和累计摸头分别计数。台词覆盖网页回复生成、完成、中断、额度状态和已确认的反重力模型步骤。
- [x] **外观联动。** 形象与壁纸可跟随桌面或保存网页独立选择，断线回退。移除 Web 自定义单图立绘入口，保留已安装角色和自定义壁纸。
- [x] **壁纸套装图库。** 网页独立图库与同步的桌面图库默认显示套装封面，点开后可逐张选用，再次点击封面可收起。
- [x] **版本检查。** Web 扩展独立检测 GitHub 正式版本。

## 待真实环境验收

- [x] **Edge 实机。** 用户确认 Edge 验收正常。
- [ ] **对话／任务切换。** 隔离 Edge Beta 验证相关结构中的原生按钮可见、可点。真实账号的差异可能与 Gemini 灰度有关，暂不阻塞。
