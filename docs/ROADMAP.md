# Catstella 路线图

「已实现」指源码已接入，实机验收单独记录。0.6.1 的 RC 3 已获用户验收，本轮通过 GitHub Actions 生成正式版三端安装包，Web 源码固定到 `web-source-v1.5.1`。

## 已实现

| 范围 | 功能 | 验证与状态 |
| --- | --- | --- |
| 在线内容商店 | 双端按壁纸、桌宠样式和主题配色分栏，支持最近更新、搜索与收藏。推荐图和详情轮播可暂停。配色可预览欢迎页与阅读区 | App 点击「查看更新」后记住已查看的素材版本。Web 在 Gemini 页内打开商店浮窗。在线壁纸套装在本地图库默认折叠，展开后可逐张选用 |
| 双端联动 | 角色、壁纸与轮播跟随桌面。Web 可保留独立选择，断线回退，重连恢复 | 已接入。Web 显示策略提供双端同显、仅桌面端 |
| 双端设置 | 形象和壁纸图库旁显示当前选用、同步状态和独立备用。Web 设置窗固定尺寸，分类内容内部滚动。Web 移除自定义单图立绘，保留旧数据 | 本地与隔离 Edge 验证 |
| Web 外观 | 星空毛玻璃、简洁实色、Gemini 原生三种界面样式。壁纸不透明度和模糊程度拖动时预览，松手后保存 | 模糊只作用于壁纸，设置窗与图库保持稳定 |
| Web 用量 | 经典进度条与反重力式圆环。圆环随内容增高，无内部滚动，默认隐藏反重力模型用量，可手动开启 | 网页组沿用网页账本，反重力组显示剩余。Argon 保留独立周额度。独立浮窗仍为 Demo |
| Web 额度归零 | 5 小时与每周到期后分别尝试刷新，切回标签页会补查。未确认新周期时显示等待更新 | 模拟账本已验，实际账号归零待验证 |
| Web 页面修整 | 去掉用量限额页外层遮罩。思考区保留原生折叠，复制提示靠近操作按钮 | 遮罩经用户实测确认，思考区和复制提示已通过隔离验证 |
| 壁纸过渡 | AGY 回前台后淡入最新壁纸。Web 修复重复通知和后台时序导致的瞬切 | AGY 已有用户实测通过，Web 偶发瞬切仍待真实轮播确认 |
| 桌宠动作 | 拖动与摸头分开，拖动时转向。桌面沿用原按压回弹，Web 保留短按反馈。确认刷新成功后播放「得意」和小跳 | Windows 单屏 150% 下验证拖动、吸附与重启恢复。跨屏和 AGY 内停靠待验 |
| 气泡布局 | 桌面标题恢复旧版单行布局。四芒星退出标题，收起按钮回到气泡右侧 | 用户反馈旧修复仍会把标题挤成两行，本轮调整后待复测 |
| 喵言喵语 | 双端统一称呼规则，网页可跟随桌面或独立设置。今日和累计摸头分别计数并触发基米台词。Web 提示回复进度、额度和已确认的反重力模型步骤 | 自动碎碎念默认关闭。反重力步骤来自本机日志 |
| 版本提示 | 双端分别查询 GitHub Releases 并提示可用正式版本，由用户决定安装。桌面更新后首次打开设置会显示当前版本更新说明，并按版本保存已读状态 | 已接入。更新说明已通过首次展示、重开不再弹出的回归。安装器与更新器一体化留作后续 |
| BYOK | 实验模块已封存于 `archive/legacy-byok/`，Windows 发行载荷已移除 | 重新启用前需验证真实 AGY 环境 |

## 当前验收和发包

- [x] **0.6.1 RC 1 回归。** 双端商店应用资产后保留详情焦点，关闭时恢复原卡片和滚动位置。隔离 Edge Beta 验证了 App 分类通知、配色预览、Web 圆环默认设置和包内离线壁纸。Windows 封装载荷通过隔离启动测试。
- [x] **Edge 登录后验收。** 用户反馈本轮无其他阻塞。Firefox Nightly 待部署后单独复测。
- [x] **商店缩略图清晰度。** 基米更新了目录中的 WebP 缩略图，双端均能读取新版缩略图。
- [x] **RC 1 实机验收。** 用户反馈测试通过，无严重问题。
- [x] **RC 3 实机验收。** 用户确认可以正式发布。低可用内存下快速摸头与台词、商店安装状态和壁纸联动已进入此版本。
- [ ] **macOS 拖动实机复测。** 旧版用户反馈桌宠在宿主窗口外且拖不动。新版修复拖动中移出命中区导致穿透的风险，CI 增加原生窗口移动和离屏恢复检查。macOS 的宿主窗口跟随仍需专门适配。
- [ ] **Web「对话／任务」切换。** 隔离环境已验证皮肤保留原生按钮。真实账号的差异可能与 Gemini 灰度有关，暂不作为发包阻塞。
- **首页黑雾。** 暂缓。
- [ ] **0.6.1 发布。** 桌面源码推进 `main`，固定 Web 1.5.1 源码标签，等待三端 Actions 构建、启动检查和校验后发布。

## 后续功能

- [ ] **统一用量计量口径。** Gemini 网页当前显示已使用百分比，反重力显示剩余百分比。后续决定统一显示已用或剩余，再对齐各个用量面板。
- [ ] **VI 与界面大更新。** 等项目作者提供设计和指定范围。候选包括设置界面翻新、常驻剩余额度浮窗、按钮重做和图标更新。
- [ ] **用量独立浮窗。** 紧凑仪表已接入 Web 桌宠，独立窗仍为演示。后续再定入口和交互。
- [ ] **更多反重力状态。** 研究工具执行、等待确认和总任务进度的可靠来源。
- [ ] **内容商店扩展。** 原型的工作区应用效果对比、素材更新与卸载、GitHub Issue 适配请求指引和模板。收藏已实现。素材发布以 `online-assets/catalog.json` 审核记录为准。
- [ ] **主题编辑与创作者工具。** 先做本地配色、透明度、实时预览和保存。壁纸与桌宠可各自选择是否捆绑。随后探索素材校验、署名、授权和人工审核后的上传流程。
- [ ] **品牌视觉与界面。** Logo、Banner 和基础 VI。新增英文、繁中、日文，机翻后分轮校对。深色模式等界面重制或大改之后再做。
- [ ] **Tauri 迁移调研。** 已测 Windows 透明窗口与整窗穿透，并建立同载荷压缩基线。先验证立绘和气泡的分区命中、拖动捕获及 Win32 宿主跟随，再决定迁移范围。

## 中长期与探索

- **Gemini Web 2025 怀旧主题。** 首选 2.5 时期，区分 3 Pro 首发时对话与思考区，以及 12 月改版。先做有可靠截图依据的可选外观。 [2.5 首页资料](https://aisig.ancstor.org/handouts/2025-05-26-aisig-gemini.pdf) · [2.5 模型菜单](https://9to5google.com/2025/05/13/gemini-model-picker/) · [3 Pro 实际对话](https://gigazine.net/news/20251119-google-gemini-3/) · [12 月改版](https://9to5google.com/2025/12/03/gemini-web-redesign-dec-2025/)
- **追加形象。** 一款先征求原作者授权，另一款参考社区形象后自行设计。形象确定后再适配表情与双端尺寸。
- **Windows 浮动任务栏重影。** 用户已实测仍复现。后续记录两端可见性与焦点时序，再验混合 DPI 和多显示器。
- **双端记忆与人格同步。** 在 Memosyne 项目里研究 DSH 社区的记忆实现与 Memmy，再定义双端接入。
- **闲置双形态与角色动画。** 探索闲置时概率变身，以及类似 dsh-pet 的角色动作，先评估立绘和播放成本。 [dsh-pet](https://github.com/zhu1090093659/dsh-pet)
- **架空界面和 Windows 客户端。** Google MD1 或 2008 年风格只保留概念。Gemini Windows 客户端适配暂不排期，等有 Catstella 特有需求再评估。 [Gemini Quota Widget](https://github.com/smiththomson580-star/gemini-quota-widget)
