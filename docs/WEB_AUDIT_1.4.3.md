## 固定渐隐实现

`content/fade.js` 创建 `#kimino-static-fade`，放在输入区容器内、输入控件下方。该层复制实际壁纸的图片、底色、透明度和几何，再对这个独立绘制层做固定渐变。内容滚动时自然从其下经过，不再修改消息透明度或逐卡 mask。

- 遮罩只属于壁纸副本，不在聊天滚动容器或玻璃卡片祖先上创建遮罩。
- 窗口、侧栏、输入框、提示条改变尺寸时才更新位置；相同几何不写入。
- 输入区常见的平移/缩放会在布局更新时校正副本坐标。
- 固定层不接受指针事件，aria-hidden；关闭主题、离开聊天或重建输入区时移除/重绑。
- 不使用单色背景盖住消息，以避免与带图案的壁纸不一致。

这种分层是为避免遮罩祖先改变 backdrop 采样边界；相关浏览器机制见 [MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter) 与 [固定定位包含块](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Display/Containing_block)。本项目仍以本地像素验证和用户真实浏览器验收为准。
