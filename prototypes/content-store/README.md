# Catstella Hub · 在线内容商店原型

在仓库中用浏览器打开 `index.html` 即可体验。默认展示设置中心的「内容商店」选项页；在地址末尾加 `#overview` 可从「总览」开始。无需安装依赖，保留仓库的相对目录即可加载设置面板样式和项目素材。

- **探索内容**：浏览两款桌宠、四张壁纸和两款主题，支持分类、关键词搜索和素材详情。详情可查看素材原样，或在模拟的 Antigravity 工作区对比「当前搭配」和「试用此素材」。预览不会切换当前设置。
- **已安装**：默认有星语、霓音、星轨紫。霓音带有演示更新。安装与使用分开；使用新素材会替换同类的当前选择。卸载需确认，收藏仍保留。
- **收藏夹**：点按素材的爱心收藏，从收藏夹可直接安装或切换已安装素材。
- **适配请求**：通过 GitHub Issue 建议适配桌宠、壁纸或主题。页面说明如何填写来源、目标平台、预期效果和授权情况，并提供可复制的模板和预填草稿。无需提前打包，Issue 由用户在 GitHub 提交。

原型复用 `Antigravity-Cat-Widget/src/renderer/settings.css` 的窗口、导航与基础控件样式。目录展示取自 `online-assets/`。演示版本与安装状态保存在当前浏览器里，不读写桌面应用配置。
