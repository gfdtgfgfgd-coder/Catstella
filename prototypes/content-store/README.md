# Catstella Hub · 在线内容商店原型

在仓库中用浏览器打开 `index.html` 即可体验。默认展示设置中心的「内容商店」选项页；在地址末尾加 `#overview` 可从「总览」开始。无需安装依赖，保留仓库的相对目录即可加载设置面板样式和项目素材。

- **探索内容**：浏览两款桌宠、两套壁纸包和两款主题配色，支持全字段关键词搜索（支持搜角色名、作者、壁纸分卷名等）和素材详情。详情可查看素材原样，或在模拟的 Antigravity 工作区对比「当前搭配」和「试用此素材」。预览不会切换当前设置。
- **重磅实装壁纸包**：
  - **《全部人类都会控猫猫的 · 壁纸包》**（全套 9 张全景）：
    - **原作**：[@森山白月](https://space.bilibili.com/2146089)（感谢老师授权壁纸 🙏）
    - **原视频发布**：[【NovelAI】Gemini - 全部人类都会控猫猫的 壁纸分享](https://www.bilibili.com/video/BV17PxC6SERc/) (BV17PxC6SERc)
    - **原视频介绍**：“是猫猫，傻傻的元气娘，是猫娘还有异色瞳，只要是人类就不可能拒绝！”
    - **分卷包括**：元气初醒 · 异色星眸、星芒跳跃 · 灿烂午后、猫耳微动 · 懵懂凝视、甜度超标 · 托腮浅笑、阳光倾落 · 纯白毛绒、元气出击 · 灵动飞扬、星轨漫步 · 温柔依偎、微风吹拂 · 俏皮眨眼、星夜流光 · 谁能拒绝。
    - **包内轮播与控制**：商店卡片与首页推荐位支持 4 秒自动轮播，带播放/暂停与手动换页；详情页提供 9 张高质感缩略图横向弹性滑动条，点选任意一张直达预览，并联动工作区效果对比。
  - **《星海漫游 · 壁纸包》**：包含星语与霓音的四幕星空经典壁纸。
- **响应式体验打磨**：
  - **宽屏与桌面端（> 960px）**：三列素材网格，Hero 推荐位宽屏图文平衡排布。
  - **平板与小窗（681px ~ 960px）**：双列网格，弹性调整比例。
  - **移动端与窄分屏（<= 680px / 540px）**：
    - 侧边栏/设置导航转为顶部横向单行顺滑滚动胶囊栏（隐藏滚动条，带柔光选中指示），不再被多列网格挤压；
    - Hero 推荐位自适应为垂直堆叠，大图置顶、文案与操作居下，视觉冲击力强；
    - 栏目导航（`hub-nav`）支持横向平滑滑动；
    - 素材网格在 `<= 540px` 下自动切换为 **单列大卡片**，避免按钮挤压，触控与操作手感大幅提升；
    - 详情页 9 张缩略图支持横向滑动吸附，当前激活项自动居中；
    - 弹窗操作与 Toast 提示贴底自适应居中。
- **已安装与收藏夹**：
  - 默认收录森山白月壁纸包与星海漫游壁纸包，安装与使用解耦；
  - 收藏夹可直达预览、安装或切换正在使用的壁纸。
- **适配请求**：通过 GitHub Issue 建议适配桌宠、壁纸或主题。页面提供直接可复制的正文模板与预填草稿链接。

原型复用 `Antigravity-Cat-Widget/src/renderer/settings.css` 的窗口、导航与基础控件样式。演示版本与安装状态保存在当前浏览器 LocalStorage 中，不影响桌面主进程的真实设置。
