创作者社区

请求适配素材

用 GitHub Issue 建议适配桌宠、壁纸或主题。每件素材单独开一条 Issue，提供来源和你想要的效果即可。

打开 Issue 草稿

01 说明想适配什么

桌宠
注明角色或形象，以及希望保留的姿势或表情。
壁纸
提供原作页面，说明是否希望保留构图、适配特定屏幕比例。
主题配色
用截图或文字说明目标配色、透明度，以及希望在工作区或网页上看到的效果。

有可公开分享的截图时，可以拖入 Issue 正文作为参考。无需提前打包素材。

02 按字段填写 Issue

标题
[适配请求][壁纸] 云海观测站。把分类和名称换成你想适配的素材。
素材来源
填写素材名称、原作者和原作链接，方便维护者找到原作。
目标平台与效果
说明希望适配桌面端、Gemini 网页或两者，以及希望保留或调整的地方。
授权情况
说明是原创、已获授权还是尚待确认；有公开许可或授权说明时附上链接。
查看可填写的正文模板

03 预览、提交与补充

登录 GitHub，打开草稿并填写标题和正文。在 Preview 检查图片和链接，再点 Submit new issue。补充截图、来源或授权时，在同一条 Issue 下回复。

维护者会评估适配方式和授权情况。提交 Issue 后，素材不会自动上架。
