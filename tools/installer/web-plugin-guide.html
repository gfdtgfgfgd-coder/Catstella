星语 · Web 端插件安装指引

安装包已把插件文件复制到本目录（web-extension）。浏览器插件需要按下面的步骤手动加载一次，之后随浏览器常驻。

Firefox（推荐 · 临时加载 / ESR 策略）

  1. 地址栏输入 about:debugging#/runtime/this-firefox 回车；
  2. 点击「临时载入附加组件…」，选择本目录的 kimino-gemini-companion.xpi；
  3. 打开 gemini.google.com，桌宠出现在头像旁。
临时加载在 Firefox 重启后失效；如需永久使用，可申请 Firefox 开发者账号自行签名，或等待我们上架 Mozilla Add-ons（从长计议中）。

Edge / Chrome（开发者模式）

  1. 地址栏输入 edge://extensions（Chrome 为 chrome://extensions）回车；
  2. 打开右上角/左侧「开发人员模式」；
  3. 「解压缩的扩展」加载本目录解压后的 kimino-gemini-companion-edge-chrome.zip（先解压），或直接把 zip 拖入页面（部分版本支持）。
每次更新插件后，在扩展卡片上点「重新加载」即可。

常见问题

· 插件只读取页面本地区域额度与状态，不上传任何数据。
· 插件与桌面端套件相互独立：桌宠读本机日志，插件读页面，双端不冲突。
· 卸载：直接在浏览器扩展页移除，并删除本目录。
