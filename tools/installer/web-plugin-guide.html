Catstella · Web 端插件安装指引

安装包会把插件文件复制到本目录（web-extension）。请按浏览器对应的步骤加载扩展。

Firefox（临时加载）

  1. 地址栏输入 about:debugging#/runtime/this-firefox 回车；
  2. 点击「临时载入附加组件…」，选择本目录的 kimino-gemini-companion.xpi；
  3. 打开 gemini.google.com，桌宠默认出现在右下角。
随附 XPI 为未签名测试包。重启 Firefox 后需要重新临时加载。

Edge / Chrome（开发者模式）

  1. 地址栏输入 edge://extensions（Chrome 为 chrome://extensions）回车；
  2. 打开右上角/左侧「开发人员模式」；
  3. 先解压 kimino-gemini-companion-edge-chrome.zip，再用「加载解压缩的扩展」选择含 manifest.json 的目录。
每次更新插件后，在扩展卡片上点「重新加载」即可。

常见问题

· 扩展在浏览器里读取额度和会话用量。桌面联动使用本机环回连接。
· 更新检测和在线图库会访问 Catstella 的 GitHub 仓库。
· 卸载：直接在浏览器扩展页移除，并删除本目录。
